Split source code in relevant information and save comments.

==== Syntax

[source]
----
procedure inspect(
    i_package_code in clob,
    i_package_name in varchar2,
    i_schema_name  in varchar2);
----

==== Parameters

|

|I_PACKAGE_NAME
|

----

==== Parameters

|===
|Parameter | Description

|I_PACKAGE_NAME
|The name of the package.

|I_SCHEMA_NAME
|
|===
