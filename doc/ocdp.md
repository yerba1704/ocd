# ora* CODEDOC publisher (OCDp)

Various __ora* CODEDOC publishers__ can use OCD to create full documentation.

## List of available projects

- The [ocd-demo](https://github.com/yerba1704/ocd-demo/) demonstration project is a good place to start for your own project. There, you can find:
  
  - the PL/SQL standalone function [example_html](https://github.com/yerba1704/ocd-demo/blob/main/hi/example_html.fnc), which returns HTML-formatted text
  - the PL/SQL standalone function [example_md](https://github.com/yerba1704/ocd-demo/blob/main/hi/example_md.fnc), which returns Markdown-formatted text
  - the PL/SQL standalone function [example_adoc](https://github.com/yerba1704/ocd-demo/blob/main/hi/example_adoc.fnc), which returns [AsciiDoc](https://en.wikipedia.org/wiki/AsciiDoc)-formatted text
